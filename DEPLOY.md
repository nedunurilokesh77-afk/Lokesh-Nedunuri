# Deploy to GitHub Pages
1. Open your repo (nedunurilokesh77-afk.github.io). Delete the old files, then upload ALL files and folders from the `site` folder (index.html, style.css, main.js, scene.js, boardtex.js, contact.js, assets/, vendor/). Commit to `main`.
2. Repo > Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
3. After ~1 minute your site is live at https://nedunurilokesh77-afk.github.io/
To update later: edit or upload the changed files and commit again.

# SEO: get found on Google (do this after deploying)
1. Google Search Console (search.google.com/search-console) > Add property > URL prefix: https://nedunurilokesh77-afk.github.io/ . Your site already has the verification tag; click Verify.
2. Sitemaps > submit: sitemap.xml
3. URL Inspection > paste your home URL > Request indexing.
4. Do the same at bing.com/webmasters (Bing > also feeds DuckDuckGo/Yahoo).
5. Add your website link everywhere you exist: GitHub profile (Website field + README), Instagram bio, LinkedIn, college profiles. These links matter most for ranking.
